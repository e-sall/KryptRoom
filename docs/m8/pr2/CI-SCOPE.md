## Exact scope

The stdlib-only `.github/ci_scope.py` classifies as presentation/documentation:

- `apps/web/**`, `docs/m8/**`.
- Explicit shared documentation files edited for M8: `PROJECT_CONTEXT.md`,
  `ARCHITECTURE.md`, `CHANGELOG.md`, `TODO.md`, `docs/DECISIONS.md`.
- The frontend workflow and the two dedicated CI scope/test scripts.

Other workflow edits are exempt **only** when their execution text is identical
after removing the event block and the exact known scope job/condition. Changes to
commands, container pins, dependencies, permissions, environment, runners or any
other conditions remain core-sensitive. A new/deleted workflow is core-sensitive.
This permits this authorized trigger-only migration without exempting future
runtime/dependency edits to cryptographic workflows.

Apart from the separately authorized, exact six-file migration described in
[M5-FIXTURE-MIGRATION.md](M5-FIXTURE-MIGRATION.md) and the two-file dependent
[M7 migration](M7-FIXTURE-MIGRATION.md), every other path, including
unknown paths, root dependency locks, Docker/Compose,
nodes, engines, schemas, chain contracts and core tests, requires core execution.
Mixed frontend/core changes require core execution. Empty diffs are conservative.
Scope code is CI policy, not a security boundary against a contributor who can
edit workflows; review these files as workflow-policy changes.

PRs use the merge-base of event base/head commits. Pushes use before/after; a new
feature branch uses its merge-base with origin/dev, never just the last commit.
Full-history checkout and local `git diff --no-renames --name-only -z` avoid
GitHub's 300-file path-filter ceiling and include deleted/old rename paths. No PR
title, label, commit-message skip directive or manually supplied trust flag.
Missing history/malformed events fail the scope job and therefore the workflow;
they never produce a successful frontend classification.

The frontend workflow additionally runs for M8/shared docs and CI-policy edits.
Its lint, unit, build, typecheck, Chromium and artifact steps remain; one stdlib
scope-test step is added. No dependency was installed or changed for these tests.
