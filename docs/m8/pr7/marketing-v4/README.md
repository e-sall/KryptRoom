# Marketing V4 visual acceptance package

This is a candidate for founder review, not visual approval or M8 completion.
Current implementation/security/test boundaries: [V4 report](../MARKETING-V4-REPORT.md).

Start with the [desktop hero](after-1440-hero.png), [1366×768 actual viewport](after-1366-showcase-viewport.png), [mobile showcase](after-390-showcase.png), [founder](after-1440-founder.png), [FAQ](after-390-faq.png) and [Product](after-1440-page-product.png). All seven desktop/mobile scenes are below. The corresponding `before-*` files show the reviewed 1ce850 candidate before V4; historical evidence is preserved.

Preview the current feature branch locally at http://127.0.0.1:3002/, then inspect Product, Technology, Solutions and booking. No public deployment. Mobile intentionally uses ordinary vertical scrolling and stable stage space; it does not miniaturize the graph.

Captures use actual Chromium 156 at DPR1 with reduced motion for deterministic inspection. DPR1/DPR2 portrait request measurements are recorded separately in [OBSERVATIONS.json](OBSERVATIONS.json). They are not live cryptographic results. Font/photo origins and hashes: [ASSET-PROVENANCE.json](ASSET-PROVENANCE.json).
